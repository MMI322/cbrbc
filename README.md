# RED — боевой расчёт

Расширение на React, Effector и Manifest V3 для мастера Cyberpunk RED. Каждая карточка хранит параметры одного противника. Дублируйте карточку для однотипной группы и нажмите «Бросить за всех», чтобы получить независимый результат для каждого противника.

Состояние боя и события находятся в `src/battleModel.ts`. Расчёт серии атак вынесен в `src/round.ts`, а чтение и запись сохранений — в `src/roster.ts`.

## Запуск

```sh
npm install
npm run build
```

- Chrome / Edge — откройте `chrome://extensions` / `edge://extensions`, включите режим разработчика и загрузите распакованную папку `crx`.
- Firefox — откройте `about:debugging#/runtime/this-firefox`, выберите «Загрузить временное дополнение» и укажите `crx/manifest.json`.
- Safari — используйте `crx` как исходную папку для упаковки в Xcode. [Инструкция Apple](https://developer.apple.com/documentation/safariservices/packaging-a-web-extension-for-safari)
- Для разработки запустите `npm run dev`. CRXJS подготавливает папку `crx` для загрузки в Chromium с обновлением при изменениях.

## За столом

Укажите базу атаки (характеристика + навык), ситуативный модификатор, тип оружия и число кубиков урона конкретного оружия. Укажите дистанцию числом или выберите диапазон кнопкой. В поле «Уклонение» можно подставить итог встречного броска цели. Пустое поле использует DV по дальности. Добавьте игроков с именем и текущим SP. Выберите игрока в поле «Цель», чтобы подставить его броню. Для любой другой цели доступен ручной ввод SP.

Одна карточка рассчитывает один выстрел. Результат показывает бросок атаки, потерю HP, SP после попадания и признак критической травмы. При пробитии брони выбранного игрока его SP обновляется автоматически. «Бросить за всех» обрабатывает противников сверху вниз, поэтому повторная атака по одному игроку использует обновлённое SP. При ручном вводе SP результат показывает новое значение для переноса.

Tab перемещает фокус, Enter в числовом или текстовом поле запускает бросок за текущего противника. Стрелки меняют числовые поля и выбор оружия. Игроки, противники и выбранные цели сохраняются в `localStorage` при каждом валидном изменении.

## Правила

Попадание требует результата строго выше порога. Натуральная 10 добавляет ещё один d10, натуральная 1 вычитает ещё один d10. При пробитии броня теряет 1 SP. Две или более шестёрки на кубиках урона дают критическую травму и ещё 5 урона напрямую в HP. [Cyberpunk RED, базовые правила, с. 129, 171–172, 186–187](https://rtalsoriangames.com/cyberpunk/) · [Разбор боевых правил от издателя](https://rtalsoriangames.com/2020/10/29/cyberpunk-red-alert-gangs-and-combat/comment-page-1/)

## Ручная проверка

После сборки откройте расширение, добавьте и продублируйте противников, закройте popup и откройте снова. Список и параметры должны восстановиться. Добавьте двух игроков с разным SP и назначьте их разным противникам. Проверьте, что пробитие снижает SP только выбранного игрока и обновляет это значение в карточках, где он выбран целью. Для пистолета на дистанции 6 м ожидается DV 13, на 7 м — DV 15, на 201 м — «Вне дальности». Проверьте бросок через Enter и кнопкой «Бросить за всех».
